# Projektbeskrivelse
- Jeg laver Løb Sammen til temaopgave 2.
- Hjemmesiden hjælper studerende på cirka 18-26 år med at begynde at løbe sammen med andre.
- Mine fem sider er: Forside, Begynderguide, Det skal du bruge, Gode råd og Første fællestur.
- Brugeren skal forstå, hvad løbet kræver, og føle sig klar til at møde op første gang.

# Teknologier
- Brug semantisk HTML og struktureret CSS.
- Brug kun simpel JavaScript, hvis det er nødvendigt, fx til mobilmenuen.
- Hjemmesiden skal være statisk og kunne uploades til mit webhotel hos simply.com.
- Hold koden enkel, så jeg selv kan forstå og forklare den.

# Projektstruktur
- Læg HTML-filerne i projektets hovedmappe.
- Forsiden skal hedde index.html.
- Læg CSS i assets/css/style.css.
- Læg billeder i assets/images og eventuel JavaScript i assets/js.
- Brug små bogstaver og bindestreger i filnavne.

# Arbejdsform
- Læs eksisterende kode, før du ændrer noget.
- Følg projektets struktur og lav kun nødvendige ændringer.
- Arbejd ét aftalt trin ad gangen.
- Brug min Figma-prototype og skemaerne fra min designanalyse som grundlag.
- Spørg, hvis vigtigt materiale eller oplysninger mangler. Gæt ikke på designets mål.
- Hjælp mig med GitHub og meningsfulde commits undervejs, så færdige deltrin bliver gemt.

# Andre vigtige ting ift. projektet
- Følg mine tekster, billeder, farver, skrifttyper og knapper fra Figma.
- Bevar brugerrejsen: Forside → Begynderguide → Det skal du bruge → Gode råd → Første fællestur.
- Forsidens primære knap skal også føre direkte til Første fællestur.
- Konceptet er gratis fællesløb i Fælledparken hver fredag kl. 16 uden tilmelding.
- Nye deltagere kan komme hver uge, og der er plads til gåpauser.
- Brug kun billeder og andre materialer med passende brugsret. Gem oplysninger om kilderne.

# Begrænsninger
- Brug ikke frameworks eller tredjepartsbiblioteker.
- Brug ikke database, login, brugerprofiler, backend, betalingsløsninger eller eksterne API'er.
- Tilføj ikke nye sider eller funktioner uden aftale.
- Ændr ikke mit design eller mine tekster uden aftale.

# Test og kvalitet
- Sammenlign hjemmesiden med Figma på desktop og mobil.
- Kontrollér, at indholdet passer til skærmen uden vandret rulning.
- Test navigation, mobilmenu, links og hele brugerrejsen.
- Brug overskrifter i logisk rækkefølge og passende alt-tekster til billeder.
- Kontrollér kontrast, tastaturbetjening og synlig fokusmarkering.

# Svar fra CODEX
- Svar kort og på dansk.
- Forklar ændringer og nye kodebegreber, så jeg kan følge med.
- Oplys, hvilke filer der er ændret, hvad der faktisk er testet, og hvilke problemer der mangler at blive løst.
- Hjælp mig med at dokumentere de faktisk brugte prompts, modeller, ræsonneringsniveauer, skills og apps. Gæt ikke på ukendte oplysninger.
